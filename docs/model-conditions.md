# Model conditions in selected evaluated configurations

This evidence view covers representative configurations with explicit catalogue records; it is not a census of all papers or experiments. The two tables refer to the same configuration IDs. Source, target and auxiliary roles remain separate.

NR means a value was not reported or was not extracted; consult the parameter evidence for the reason. NR is never zero. N/A denotes an inapplicable role or parameter-count concept. Reported model-size labels are preserved without estimating missing counts from architecture names.

Separate runs within a paper must not be read as a single fused model. Some evidence records explicitly group alternative students or compatible base families; their stated separation is retained. These records are unsuitable for mutually exclusive model-family statistics.

Coverage: 5 papers; 7 configuration evidence records. Generated from optional `model_configurations` entries in `data/papers.json`.
